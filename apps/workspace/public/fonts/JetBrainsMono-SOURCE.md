# JetBrains Mono

Official source: https://github.com/JetBrains/JetBrainsMono
Pinned revision: 19371302b95d218af43299bce79ddbddd0bc364d

Regular and Medium TTF and WOFF2 files are distributed under the bundled
OFL-JetBrainsMono.txt. Web controls use WOFF2; PDF/image exports use the same
packaged TTF outlines so output does not depend on fonts installed by a host.
